🌐 Subnetting IPv4 y segmentación con VLAN

Laboratorio 1 · Ethan Beltrán · 2026

🎯 Propósito

Dividir la red 192.168.10.0/24 en cuatro subredes y aislar cada departamento en su propia VLAN. La segmentación limita el alcance de un incidente y permite aplicar controles de seguridad por área.

🗺️ Topología (router-on-a-stick)

                 [ R1 - Router 2911 ]
                        | G0/0  (subinterfaces .10 .20 .30 .40)
                        | enlace troncal 802.1Q
                        | G0/1
                 [ SW1 - Switch 2960 ]
       Fa0/1-5     Fa0/6-10     Fa0/11-15     Fa0/16-20
      VLAN 10      VLAN 20       VLAN 30       VLAN 40
   Administración   Ventas         TI         Invitados

🧮 Plan de direccionamiento

4 subredes → 2 bits prestados → máscara /26 (255.255.255.192), 62 hosts útiles por subred.

VLANRedRango de hostsBroadcastGateway

⚙️ Configuración

Switch SW1 
vlan 10
 name ADMINISTRACION
vlan 20
 name VENTAS
vlan 30
 name TI
vlan 40
 name INVITADOS
interface range fa0/1-5
 switchport mode access
 switchport access vlan 10
! (igual para 20, 30 y 40)
interface g0/1
 switchport mode trunk
Router R1 
interface g0/0
 no shutdown
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.192
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.10.65 255.255.255.192
interface g0/0.30
 encapsulation dot1Q 30
 ip address 192.168.10.129 255.255.255.192
interface g0/0.40
 encapsulation dot1Q 40
 ip address 192.168.10.193 255.255.255.192

🔐 Reflexión de seguridad

  • Un equipo comprometido en Invitados no ve el tráfico de capa 2 de Administración.
  • Mejora futura: una ACL en g0/0.40 para que Invitados no alcance las demás VLAN.
  • Apagar los puertos del switch que no se usan.
